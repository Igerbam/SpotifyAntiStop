# SpotifyAntiStop
Wenn Spotify als Anwendung auf Discord mit Screen Share geteilt wird, wird Spotify alle 30 Sekunden automatisch pausiert. Dieses Skript verhindert das.\
Dieses Skript pausiert Spotify selbst alle 25 Sekunden, aber nur für ein Bruchteil einer Sekunde, sodass der interne Timer von Spotify dann immer auf 30 Sekunden zurückgesetzt wird. Bei jedem pausieren wird geprüft, ob das Spotify-Fenster gerade aktiv ist. Wenn ja, dann wird die Leertaste benutzt. Wenn nicht, dann wird die Medientaste benutzt.

**Keine einzige Zeile Code** in diesem Projekt wurde mithilfe von AI erstellt.
